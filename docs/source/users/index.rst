Users
=====

Follow this stream to log in, create API credentials, submit metadata, and
upload and download files. Ask your operator for the portal URL and an account
with the required project permissions. The examples use synthetic training
data and an existing model supplied by a data manager.

.. toctree::

The SDK examples create a program/project when authorised, upload a file,
register its graph metadata, and download it by GUID. Existing projects may
skip creation. Follow the registration page's prerequisite steps to submit
parent records before their file metadata.
