Gen3 Python SDK
===============

Install the SDK, create a program and project, upload a sample file, register
its metadata, and download it using API credentials.

.. figure:: /images/02-gen3-architecture.png
   :alt: Gen3 architecture showing front-end applications, APIs, and back-end services.
   :align: center
   :width: 100%

   The Gen3 Python SDK calls the APIs provided by Gen3 services. The examples
   below use these APIs to create projects, upload files, submit metadata,
   and download files.
