Local Gen3 Deployment
=====================

This section covers the prerequisites and step-by-step deployment of the
repository's local Gen3 training environment, including the Talos cluster,
MinIO, LDAP and Dex, the Gen3 application, browser login, and search refresh.

The playbooks currently run on macOS. Debian prerequisite installation is
documented, but the playbooks themselves do not yet support Debian as the
deployment host.
